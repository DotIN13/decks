The loop

Nothing is ever serialised from a tree into the file: the server's tree is only asked where the bytes are. And a node with no handle cannot be pressed at all — which is why what a script drew, and a <b> inside a paragraph, never need a rule saying they are not targets. They are not in the tree.

One frame, two modes — the mode changes interaction and nothing else

Same board, same rendering Browse Edit
A press inside it selects the board selects the node under the pointer
A drag moves the board moves the node, snapped, if it has left/top
A second click on a run of words — a caret in it
Inside a drawn panel — its source is offered; what the script drew has no handle
Escape the canvas's use leaves the mode

Toggling does not reload: scroll, a live box, a running animation all survive. And there is no save step — a drag commits when the pointer is released, a retype when the caret leaves — so the mode cannot lose work.
