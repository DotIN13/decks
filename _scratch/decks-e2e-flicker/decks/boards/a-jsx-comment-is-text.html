Summary

Ninety words of a source comment were drawn on the canvas, under all eight boards. In the children position of JSX, a block comment is not a comment — it is a text child. It is also valid JSX, so nothing in the toolchain objected: the type checker was happy, esbuild strips it, and Solid's compiler — which is what runs here — emitted it as a string and rendered it. The comment is in braces now, and geometry.mjs asserts that nothing drawn on the canvas came out of a source comment, because the DOM is the only place this is catchable.

Measured

MomentText nodes carrying source delimiters
before, on the canvas8 — one inside each .board-node, which is what “under every board” means
after, on the canvas2 — both inside <style> elements, where a comment is a comment

The probe walks every element's own child nodes, not its descendants' — a leaked comment is a text node, and the board's title is a text node too, so the distinction is the measurement.

My first detector was an esbuild scan, and it reported “no comment is rendered as content” while the text was on screen. The compiler that runs in the app is the only one whose answer counts — and the running DOM is its answer.

The other sixteen

Sixteen other comments in the app end on the line right before an element, which is what the leak looked like. All sixteen are in expression or attribute position — the block sits after return ( and before the root element, or inside a fallback={…} — where the comment is dropped as a comment. The distinction is not the shape of the comment but where it sits: inside an element's children is the only position that makes it text.

Which is also why the fix cannot be “careful”: the next person to add a comment there has no signal at all. The braces are load-bearing, and the comment now says so on itself.

The assertion

geometry.mjs: no element on the canvas may hold a text node containing a source comment's delimiters, <style> and <script> excepted — since those two are source, and a comment in them is doing its job. 19 assertions, none failing. It is a general claim about the canvas rather than about boards, so it catches the next one of these wherever it is written.
