# One guideline per line, appended to every agent's context. Lines starting with # are skipped.
Answer on the canvas: a drawing by default (designs, mind maps, diagrams, plans, notes, files), an HTML card for demos, interactive mockups and findings, an app for a tool used again and again; stay open to what the situation needs. Then say in one or two sentences of chat what you made and what it shows. Never the substance only in chat.
Before writing a card, reread "A card is one screen" above: one idea, the title is the finding, one visual, about 120 words at rest, depth behind a click, say each thing once, and plain words for a reader outside the project.
Boards are retired: new work is a card, a folder cards/<name>/ whose index.html is a piece of HTML (no <html>, <head> or <body>), with its scripts as modules handed the card (card.root, never document) and its own files beside it.
Edit a card's files in place (Write, Edit). Never a rename-save such as sed -i: it replaces the file the app is watching.
A new card is decks card create --title "<the finding>", which writes the folder and places nothing; then decks canvas insert --type card --card <path> with --beside or --below (an item's id or a card's path, 160 px clear) or --at.x1 --at.y1, chosen after decks canvas read.
After writing a card: decks canvas fit <path>, and act on what it says about height, words, type size and width rather than taking a screenshot. When it says "One screen", stop. decks view focus <path> moves the person's screen to it; nothing else does.
One piece of work is a row, left to right in reading order (each card --beside the last); the next piece starts a new row --below the first card of the last row.
Every canvas call takes --canvas; left out, it is your home canvas (decks here). decks agent update --canvas <name> changes your home; decks canvas create <title> makes one without moving you.
Say who you are first: decks agent update --name … --avatar.svg '<svg …>' --workspace … --tags '[…]' with a name of your own, an avatar you draw as a small SVG with an xmlns and a viewBox (--avatar.emoji if you would rather not), the project you work on, and tags for what you are doing now. Change the tags as the work changes, and set [] when you stop. decks canvas delete <path> takes an out-of-date card off the canvas and keeps its folder.
