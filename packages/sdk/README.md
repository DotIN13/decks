# @decks/sdk

Every Decks verb, three ways, all made from one table (`packages/api`) and all calling one
endpoint, `POST /api/v1/<verb>`:

| Form | For | Looks like |
| --- | --- | --- |
| TypeScript, `src/index.js` | apps, the browser, node scripts | `await decks.move(path, { x: 640, y: 0 })` |
| The `decks` command, `bin/decks` | an agent's shell, any script | `decks move boards/a.html --x 640 --y 0` |
| MCP, `mcp/server.mjs` | agents that can only call tools | the tool `decks_move` |

One file, no dependencies, Node 18+ or a browser. The server runs no code of yours: each call is
one verb with its arguments as JSON, checked against the table before anything runs.

```js
import { decks } from "@decks/sdk";          // DECKS_URL and DECKS_AGENT from the environment

const path = await decks.newBoard({ title: "Q3 revenue", at: { x1: 0, y1: 0 } });
await decks.show(path);
for (const board of await decks.boards()) if (board.clipped) await decks.fit(board.path);
```

```sh
p=$(decks new-board --title "Q3 revenue" --at.x1 0 --at.y1 0)
decks show "$p"
decks boards | jq -r '.[] | select(.clipped) | .path' | xargs -n1 decks fit
echo '[{"op":"delete","id":"n1"}]' | decks pen edit -
decks help new-board
```

## Who is calling

| Caller | How it connects |
| --- | --- |
| An **agent** | Decks puts `DECKS_URL`, `DECKS_AGENT` and the `decks` command in each agent's shell |
| A Decks **server app** | Decks sets `DECKS_URL`, `DECKS_APP` and `DECKS_SDK` (this file's path): `const { decks } = await import(process.env.DECKS_SDK)` |
| A Decks **app page** | `import { decks } from "../../api/sdk/decks.mjs"`; the app is found from the page's address |
| Anything else | `connect({ url, agent })` |

An app's first call makes Decks ask the person whether that app may use the stage, and each call
is noted in the conversation on screen. Who is calling is said, not proven, for now.

## What to know

- A verb answers with its value. The notes it adds (what `fit` measured, where a board went) go to
  stderr in Node, or to `connect({ notes })`; `decks.call(verb, args)` gives value, notes and
  pictures together.
- A refused or failed call is a `DecksError` with `message`, `status` and `notes`.
- The `decks` command prints a string value as it is (so `$(decks new-board …)` is the path) and
  anything else as JSON; notes and refusals go to stderr, and a refusal exits with 1.
- `src/index.d.ts`, the verb list in `src/index.js` and `src/verbs.json` are generated by
  `node --import tsx scripts/gen-sdk.mjs` from the table; a test fails when they drift.
- `DECKS_TOOLS=stage,pen,boards` narrows the MCP server to some groups.
